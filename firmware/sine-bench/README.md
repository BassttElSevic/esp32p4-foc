# DENG FOC 2208 实机正弦测试

本工程面向 ESP32-P4、M2 通道、AS5600、双极性 INA199A1 和两只 R015 分流电阻。板上按实际采样时间生成零均值正弦参考，分别测试两个闭环。电流模式直接注入转子坐标的有符号 `iq*`（mA），速度外环断开；速度模式注入电角速度给定（电 rad/s），保留速度和电流 PI。激励频率的单位均为 Hz。每次运行一段有限时长的波形。新版实验固件需要在你的台架上完成首次验证。

## 首次接线与上电

1. 固定电机座，卸下桨叶、飞轮及外部负载，给转轴预留自由转动空间。标定会施加磁场并移动转子，手和导线离开旋转区域。**电流模式下转子也可能加速。**
2. 核对 M2 的 U/V/W PWM 为 GPIO26/27/32，EN 为 GPIO33、高有效，电流 U/V 为 GPIO22/23，编码器 SCL/SDA 为 GPIO8/7。分流器 15 mΩ、增益 50、两路零电流输出均约 1.65 V。旧 R500 板或 REF 接地的板子与本工程量程不匹配。
3. 用可限流的 12 V 台式电源供电，并准备能立即切断**电机母线**的实体开关。软件相电流阈值与电源显示的直流母线电流是不同测量。检查驱动 EN 在 MCU 复位、刷写、掉电时由硬件下拉保持关闭。首次刷写时切断电机母线，仅给 MCU / 串口供电，尤其从会自动标定的旧固件切换时。
4. 在 ESP-IDF 6.0.1 环境中，从本目录手动执行下列命令。按你的机器替换端口。刷写后关闭串口监视器，PC 工具独占 115200 baud 的 CH343 UART0。

```sh
idf.py set-target esp32p4
idf.py build
idf.py -p COM5 flash
```

## 单次试验

在仓库根目录安装依赖并查询状态。PC 不主动触发复位，某些 USB 串口适配器在打开端口时仍可能切换控制线。此固件复位后回到 `UNCAL`，EN 保持低电平。

```sh
python -m pip install numpy pyserial
python tools/sine_bench.py --port COM5 status
```

确认返回 `UNCAL`、转轴空载、人员已离开旋转区域，再接通电机母线，**显式**运行一次标定。该步骤检查两路电流零点、磁体状态、定向电流符号和转子的相对位移。若失败，先切断动力，检查接线、磁铁、采样极性和夹具，排除原因后再标定。正常完成后 EN 变低，状态为 `IDLE`。以下每条试验命令都是一次独立的机械动作，先查看第一组结果再执行下一组。

```sh
python tools/sine_bench.py --port COM5 calibrate
python tools/sine_bench.py --port COM5 current --frequency 2 --amplitude 15 --cycles 6 --output current_2Hz.csv
python tools/sine_bench.py --port COM5 speed --frequency 1 --amplitude 2 --cycles 5 --output speed_1Hz.csv
```

电流示例的峰值为 **15 mA**、持续 3 s；速度示例的峰值为 **2 电 rad/s**、持续 5 s（7 极对，给定峰值约 2.73 机械 rpm，实际转速可能超出给定）。这些是检查方向、信号和采样质量的起始工况。报告中的 0.1 µA 电流幅值远低于这套采样链的分辨能力；87.22 Hz 是平滑模型的共振点，也超出本实验固件的范围。短记录无法复现仿真中约 2060 s 的自由轴电流调节过程。

运行中可用 **Ctrl+C** 让 PC 请求停止；若正在用独占的手工串口终端，可发送 `stop`。失控、异常声响或意外运动时直接切断电机母线。EN 拉低撤去驱动力，转轴可能继续滑行。故障后需要人工重新标定。PC 不自动重试或提高激励。

## 板端边界

| 项目 | 本实验固件的限制 |
|---|---|
| 正弦激励 | 0.5–10 Hz，3–12 个完整周期，且总时长 ≤8 s |
| 给定上限 | 电流峰值 ≤60 mA；速度峰值 ≤5 电 rad/s，速度 PI 输出限于 ±60 mA |
| 电压与电流 | 测试调制矢量 ≤0.12；标定场 ≤0.10。任一采样时刻三相重建电流峰值 ≥220 mA 即撤 EN |
| 速度 | 原始角差估速绝对值 >60 或滤波估速绝对值 >35 电 rad/s 时退出；含编码器量化影响 |
| 看门狗 | PC 每约 100 ms 续租；板端租期 500 ms。独立 `esp_timer` 任务每约 2 ms 检查，已使能时控制数据超过 10 ms 无更新则撤 EN。正常结束和故障都先撤 EN |
| 测量健康 | 每拍核对 ADC 读数、量程和 AS5600 磁场状态。标定/测试前逐路核对 1.2–2.1 V 零点及静止窗口；正常读角和测流都必需 |

定时器、传感器和 EN 控制均依赖 MCU 工作。这些软件检查无法替代硬件限流、实体断电和机械防护，也不能检测所有峰值或电机温升。

## 记录与分析

控制 PI、极对数、硬件映射及坐标变换参数来自[共享参数](../foc/main/foc_parameters.h)。控制循环按实测间隔推进，内存约每 4 ms 记录一行，结束或故障撤 EN 后再通过串口导出，避免运行时打印阻塞。CSV 保存板端微秒时间、带单位的给定、原始/滤波 $q$ 轴电流、角差/滤波电角速度、AS5600 原始 12 位机械角码、限幅标志及结束原因；文件独占创建。实际采样间隔可从相邻时间戳求得。

PC 对最后两个周期按板端时间拟合正弦与余弦分量，输出相对于记录给定的幅值比、相位和拟合质量。记录有缺口、出现限幅、信号分辨率不足或末两个周期不一致时，工具说明相应结果不可判读。两个速度通道均来自同一 AS5600；比较模型中的真实轴速峰值需要另接独立测速设备并同步采样。一组有限窗记录本身无法证明已经达到稳态，也无法直接给出开环相位裕度或增益裕度。

驱动停止后可在手工终端用 `bench status` 查询，用 `bench dump` 重读保留的原始记录。缓冲只保存最近一次动作，下一次标定、测试或复位会清除。板端单次边界位于[bench.c](main/bench.c)，PC 工具位于[sine_bench.py](../../tools/sine_bench.py)。
