# DENG FOC 2208 小角度往复运动的台架辨识模型

本模型用于比较当前台架在零速附近的正弦电流和速度响应。首批两份 2 Hz 电流记录（峰值 60、150 mA）和一份 1 Hz 速度记录（峰值 2 电 rad/s）用于辨识，01–04 组的八份记录整组留作验证。各组只使用试验记录中的 PI 与滤波参数，不重新拟合电机。四条总图曲线分别为输入正弦、台架实测、原名义模型和本次辨识模型。[打开本地模型](bench_local_2208.slx) · [单页矢量图](model_comparison.pdf) · [PNG 预览](model_comparison.png)

## 对象方程

沿用原模型的七极对、正弦反电势、零凸极近似及 $dq$ 电压方程。电流用 A，角位移用机械 rad，$\omega_e=p\dot\theta_m$。$\theta_0$ 为该次试验起始的小角度平衡位置。

$$
\begin{aligned}
L_d\dot i_d &= v_d-R_{\rm eff}i_d+\omega_e L_q i_q,\\
L_q\dot i_q &= v_q-R_{\rm eff}i_q-\omega_e(L_d i_d+\psi_m),\\
J\ddot\theta_m+B_{\rm eff}\dot\theta_m+k_\theta(\theta_m-\theta_0)&=K_t i_q,
\qquad K_t=\tfrac32 p\psi_m .
\end{aligned}
$$

| 系数 | 原名义模型 | 台架辨识模型 | 含义 |
| --- | ---: | ---: | --- |
| $R_{\rm eff}$（Ω） | 18.76 | 9.2174 | 从电流控制器重建电压得到的等效系数，按两轴相同处理 |
| $B_{\rm eff}$（N·m·s/rad） | 0.00000107 | 0.0035761 | 低速换向时与速度同相的等效阻力矩系数 |
| $k_\theta$（N·m/rad） | 0 | 0.17896 | 平衡点附近与位移成正比的等效恢复力矩系数 |

惯量 $J=5.0\times10^{-7}$ kg·m²、$L_d=L_q=2.58$ mH 和磁链沿用名义先验，对应 $K_t=0.089821$ N·m/A。恢复项只在当前小摆幅附近使用；连续旋转时不能把与累计角度成正比的转矩外推到整圈。两种模型使用相同的逆变器、ADC 和编码器量化、控制器与板端保护。[原模型参数](../../simulink/esp32p4_foc_data.m) · [辨识参数文件](parameters.csv)

## 参数如何得出

取各训练记录最后两个给定周期，按时间戳拟合正弦、余弦和常数项；对解开角码回绕后的机械角再加入线性漂移项。以下 $I_q$ 取原始 $q$ 轴电流的基波；重建电流 PI 时，误差则取给定减去固件实际使用的滤波反馈。

1. **电气项。** 按固件的离散 PI 及上一拍积分状态，用给定和滤波反馈之差重建调制指令的基波。采用名义 12 V 母线、零阶保持和名义磁链，扣除由编码器角度基波计算的反电势，取等效阻抗的实部。两次试验分别给出 9.55 Ω 和 8.88 Ω，取等权平均。这里没有实测绕组端电压，结果可能包含驱动增益、采样误差与模型简化的影响。
2. **机械项。** 在 1 Hz 速度记录中得到 $I_q/\Theta_m=1.99223+j0.25016$ A/rad。由 $I_q/\Theta_m=(k_\theta-J\Omega^2+jB_{\rm eff}\Omega)/K_t$，在给定 $J,K_t$ 下求得 $k_\theta/K_t=1.99245$ A/rad 和表中的 $B_{\rm eff}$。相位偏差也会进入速度系数；该估计没有单独辨识轴承摩擦或齿槽转矩。[辨识脚本](../../analysis/identify_bench_local.m)

## 留组验证结果

下表给出末两个完整周期的同频基波。速度、电流的百分数均为滤波反馈基波幅值除以给定基波幅值；角度单列为机械角基波峰值。

| 完整的留出试验 | 原名义模型 | 台架辨识模型 | 实机 |
| --- | ---: | ---: | ---: |
| 01 组，1 Hz 速度幅值比 | 99.5% | 19.9% | 22.4% |
| 02 组，1 Hz 速度幅值比 | 99.4% | 20.3% | 20.1% |
| 02 组，同次机械摆幅 | 2.599° | 0.527° | 0.555° |
| 03 组，2 Hz 电流幅值比 | 91 ms 保护停机 | 40.5% | 44.6% |
| 04 组，2 Hz 电流幅值比 | 54 ms 保护停机 | 58.5% | 68.8% |

01、02 组滤波估速的基波拟合较弱，角度记录提供了另一种核对。在这两组的全部 1 250 个速度样点上，时域均方根误差分别从 1.142、1.159 电 rad/s 降至 0.408、0.361 电 rad/s。01、02 组 2 Hz 电流的时域均方根误差也分别从 17.77、14.81 mA 降至 9.61、7.19 mA；局部模型仍低估电流基波。03、04 组的名义电流预测提早结束，其同窗比较只有 23、14 点。单独看辨识模型在这两份完整记录上的 750 个样点，误差分别为 2.91、5.43 mA。

**适用边界。** 03、04 组的实机速度试验均以 `overspeed` 中止，最后的台架样点位于 1.012 s 和 0.024 s。新模型两次都完成 5 s，漏掉两次保护；04 组仅有 7 个共同样点，该窗的速度误差还比名义模型大。150 mA 电流训练试验本身也有残差：新模型虽然跟上电流基波（37.84 mA，实测 37.80 mA），却只预测了 1.06° 机械摆幅，实测 1.95°。一组等效参数尚不能解释所有振幅、所有转子起始位置或高增益下的异常。模型支持这里的低速小角度比较，现有数据不足以验证全速域、带宽或保护边界。

## 复现与查看

直接打开本目录的 SLX，可以查看或运行默认的 1 Hz 速度试验。Model Workspace 内嵌参数，`bench_speed=1` 选择速度给定，设为 0 选择电流给定。`bench_amp` 分别以电 rad/s 或 mA 为单位，`bench_hz` 为激励频率，`bench_duration` 控制时长。`sampleLog` 保存给定、原始/滤波 $i_q$、原始/滤波电角速度、限幅标志和保护码；`shaftLog` 保存机械角。

从仓库根目录运行以下 MATLAB 命令可重新辨识，并以原名义模型、辨识模型各跑 11 个工况。CSV 按板端时间与最近的仿真控制拍配对，三方均有效的样点才进入横向 RMSE。角度在每个记录的首个配对时刻归零。完整末两个周期的基波幅值另列在结果表内，提前停机工况也保留其原始长度和停机信息。[两模型验证入口](../../analysis/compare_bench_local.m) · [各工况指标](metrics.csv) · [逐点波形](waveforms.csv)

```matlab
addpath('analysis')
metrics = compare_bench_local;
```

绘图需要 Python、NumPy、pandas、Matplotlib 和中文字体。在仓库根目录执行：

```sh
python analysis/plot_local_bench_model.py
```
