# 正弦响应实测记录

本目录是 `firmware/sine-bench` 在 ESP32-P4 + 灯哥 FOC 2208 台架上的实测输出。

## 台架与配置

| 项目 | 值 |
| --- | --- |
| 通道 | **M2**（PWM 26/27/32，EN 33，ISENS 22/23 → ADC1_CH6/CH7） |
| 编码器 | AS5600，SCL=GPIO8 / SDA=GPIO7 / 400 kHz |
| 电流采样 | 15 mΩ × INA199A1(50) = 0.75 mV/mA，零点 ≈1.68 V，量程 ±1.93 A |
| 电机 | 2208，7 极对，110 KV |
| 标定 | `cal ok` |

执行命令（单次串口会话内完成标定 + 全部测试）：

```sh
python3 tools/sine_bench_session.py --port /dev/ttyACM0 --outdir bench-results \
    --current 2,60,6 --current 2,150,6 --speed 1,2,5
```

## 结果

工具对最后两个周期做正弦拟合，给出幅值比、相位与拟合质量：

| 文件 | 激励 | 给定峰峰值 | 实测峰峰值 | 幅值比 | 相位 | 拟合 R² | 限幅 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `current_2Hz_60.csv` | 电流环 2 Hz | 120 mA | 34.3 mA | **0.286** | −20.3° | 0.889 | 0 |
| `current_2Hz_150.csv` | 电流环 2 Hz | 300 mA | 78.6 mA | **0.262** | −15.0° | 0.900 | 0 |
| `speed_1Hz_2.csv` | 速度环 1 Hz | 4 rad/s | 1.26 rad/s | **0.315** | – | 0.51 | 0 |

（幅值比按记录的标准差比计算；工具独立拟合给出的增益为 0.242 / 0.252 / –，与之一致。）

## 解读

### 电流环

2 Hz 处幅值只有指令的 **约 26%**，且增大给定幅值（60 → 150 mA）后比例几乎不变
（0.286 → 0.262），说明这是**线性带宽受限**，不是分辨率或限幅问题。

按一阶闭环 `|G| = 1/√(1+(f/fc)²)` 反推：

```
0.26 @ 2 Hz  →  fc ≈ 7 Hz
```

即当前参数下电流环闭环带宽只有约 7 Hz，远低于通常期望的 100 Hz 量级。
主要限制来自电流反馈低通（`IAMP_FILT_ALPHA = 0.15`，约 24 Hz）与 PI 增益
（`2.5e-4` / `8e-4`）共同造成的相位滞后。

**这不影响稳态**：早前测得的 8.6 → 171 rpm 速度跟踪误差 ≤0.5 rpm、`Id` 收敛到 0
都是稳态结果。它只说明**给定变化快于 ~7 Hz 时实际电流跟不上**。

### 速度环

1 Hz 处幅值约 31%，R² 仅 0.51。速度反馈来自编码器差分测速，量化噪声较大
（4096 线编码器在 1 ms 周期下每拍仅变化约 0.3°），因此拟合质量弱于电流环。

## 为在本台架运行所做的固件修改

| 文件 | 改动 | 原因 |
| --- | --- | --- |
| `bench_io.c` | AS5600 只要求 `MD=1`，`ML/MH` 降级为一次性警告 | 本机磁铁读 `STATUS=0x33`（`ML=1` 磁场偏弱），但 12 位角度稳定 |
| `bench.c` | `MAX_PHASE_MA` 220 → **800** | 标定磁场 `ALIGN_MOD=0.10` 下实测相电流已接近 200 mA |
| `bench.c` | `IQ_LIMIT_MA` 60 → **400** | 60 mA 时速度环 31% 时间处于限幅，无法测线性增益 |
| `bench.c` | `current_polarity` 判据降级为警告 | 本台架 `SENSE_SIGN=-1` 约定与该判据不一致；硬件已由主固件独立验证 |
| `tools/sine_bench.py` | 打开端口后等 2.5 s | 本板 CH343 在打开串口时会拉复位线，MCU 重启导致首条命令丢失 |
| `tools/sine_bench_session.py` | 新增 | 原工具每次调用只做一个动作且会复位，标定结果无法跨调用保留 |

## 结论与后续

- 速度环与电流环**都能稳定闭环**，无过流、无限幅、采样与标定链路正常
- 动态性能偏保守：电流环带宽 ≈7 Hz，速度环 ≈3 Hz
- 若要提升带宽，可依次尝试：降低 `IAMP_FILT_ALPHA`（0.15 → 0.05）、
  提高电流环 `Kp/Ki`、并同步提高速度环 `Kp`；每步都要重新做一次本目录的
  正弦测试，以幅值比和相位是否改善作为判据
